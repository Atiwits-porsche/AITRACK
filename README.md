# AITRACK · แอปบันทึกรายรับรายจ่าย

เว็บแอปสำหรับบันทึกรายรับ–รายจ่ายรายเดือน พร้อมหน้าสรุปที่อ่านง่าย ใช้งานได้ทั้งบนมือถือและคอมพิวเตอร์
ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์ ข้อมูลเก็บในเบราว์เซอร์ของคุณเอง และใช้งานออฟไลน์ได้

## ฟีเจอร์

| หน้า | สิ่งที่ทำได้ |
|---|---|
| 🧾 **รายการ** | ดูรายการของเดือน จัดกลุ่มตามวัน · การ์ดสรุปรายรับ/รายจ่าย/คงเหลือ · แถบงบประมาณ (เตือนเมื่อใช้เกิน 80%) · กรองรายรับ/รายจ่าย · ค้นหา · แตะรายการเพื่อแก้ไข/ลบ (มีปุ่มเลิกทำ) |
| 📊 **สรุปเดือน** | เทียบกับเดือนก่อน · อัตราการออม · แผนภูมิวงกลมรายจ่ายตามหมวด + ตาราง · รายรับตามหมวด · 5 รายจ่ายสูงสุด · กราฟรายจ่ายรายวัน · พิมพ์/บันทึก PDF |
| 📅 **สรุปปี** | กราฟรายรับ vs รายจ่าย 12 เดือน · ตารางสรุปรายเดือน (แตะเพื่อเปิดสรุปเดือนนั้น) · รายจ่ายตามหมวดทั้งปี · พิมพ์/บันทึก PDF |
| ⚙️ **ตั้งค่า** | ตั้งงบรายเดือน · เพิ่ม/แก้ไข/ลบหมวดหมู่ · ส่งออก CSV (เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน) · สำรอง/กู้คืนข้อมูล (JSON) · ข้อมูลตัวอย่าง |

ปุ่มลัด: `N` เพิ่มรายการ · `←` `→` เปลี่ยนเดือน · รองรับโหมดมืดอัตโนมัติ · ติดตั้งเป็นแอปบนมือถือได้ (PWA)

## วิธีใช้งาน

**แบบเร็วที่สุด:** ดับเบิลคลิก `index.html` เพื่อเปิดในเบราว์เซอร์

**แบบรันเป็นเว็บเซิร์ฟเวอร์** (จำเป็นสำหรับโหมดออฟไลน์/ติดตั้งเป็นแอป):

```bash
npm start
```

แล้วเปิด http://localhost:8080

**เผยแพร่ออนไลน์ฟรีด้วย GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → เลือก branch และโฟลเดอร์ `/ (root)`
จากนั้นเปิดลิงก์บนมือถือแล้วเลือก "เพิ่มลงในหน้าจอหลัก"

> ⚠️ ข้อมูลเก็บใน `localStorage` ของแต่ละเบราว์เซอร์/อุปกรณ์ ไม่ซิงก์ข้ามเครื่อง — ใช้ปุ่ม "สำรองข้อมูล" ในหน้าตั้งค่าเป็นระยะ

## โครงสร้างโค้ด

```
index.html            โครงหน้า + ฟอร์มบันทึก
css/style.css         ธีมสว่าง/มืด, layout responsive, สไตล์สำหรับพิมพ์
js/utils.js           ฟังก์ชันคำนวณ/จัดรูปแบบ (ไม่แตะ DOM, ทดสอบได้)
js/store.js           จัดเก็บข้อมูลใน localStorage, หมวดหมู่เริ่มต้น, นำเข้า/ส่งออก
js/charts.js          กราฟ SVG (วงกลม, แท่ง) ไม่ใช้ไลบรารีภายนอก
js/app.js             หน้าต่าง ๆ, routing, ฟอร์ม, tooltip, toast
sw.js, manifest.webmanifest   รองรับออฟไลน์และติดตั้งเป็นแอป
tests/                unit tests (node:test)
```
