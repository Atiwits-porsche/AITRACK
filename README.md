# AITRACK · แอปบันทึกรายรับรายจ่าย

เว็บแอปสำหรับบันทึกรายรับ–รายจ่ายรายเดือน พร้อมหน้าสรุปที่อ่านง่าย เปิดผ่านลิงก์ได้จากทุกอุปกรณ์
ล็อกอินด้วยอีเมลแล้วข้อมูลจะซิงก์ผ่าน **Supabase** อัตโนมัติ (มือถือ ↔ คอมพิวเตอร์ อัปเดตแบบเรียลไทม์)
ยังใช้งานต่อได้แม้ออฟไลน์ แล้วจะส่งข้อมูลขึ้นเองเมื่อกลับมาออนไลน์

## ติดตั้งให้เป็นลิงก์ใช้ได้ทุกเครื่อง (ทำครั้งเดียว ~10 นาที)

### 1. สร้างฐานข้อมูลบน Supabase (ฟรี)
1. สมัคร/เข้าสู่ระบบที่ [supabase.com](https://supabase.com) → **New project** (เลือก Region: Southeast Asia (Singapore))
2. เมนู **SQL Editor** → New query → คัดลอกเนื้อหาไฟล์ [`supabase/schema.sql`](supabase/schema.sql) ไปวาง → **Run**
   (สร้างตาราง `transactions`, `user_settings` พร้อม Row Level Security ให้แต่ละคนเห็นเฉพาะข้อมูลของตัวเอง และเปิด Realtime)
3. เมนู **Project Settings → API Keys** คัดลอก **Project URL** และ **anon / publishable key**
   (⚠️ ห้ามใช้ `service_role` / secret key)
4. ใส่ค่าทั้งสองใน [`js/config.js`](js/config.js) แล้ว commit

> **อัปเดตจากเวอร์ชันก่อน?** รัน `supabase/schema.sql` อีกครั้งใน SQL Editor (รันซ้ำได้ ไม่กระทบข้อมูลเดิม)
> เพื่อเพิ่มคอลัมน์ "เวลา" และ "แผนรายเดือน" — ถ้ายังไม่รัน แอปยังใช้งานได้ แต่เวลาและแผนจะยังไม่ซิงก์ข้ามเครื่อง

### 2. เปิดเว็บด้วย GitHub Pages (ฟรี)
1. GitHub repo → **Settings → Pages** → Source: *Deploy from a branch* → เลือก branch (เช่น `main`) และโฟลเดอร์ `/ (root)` → Save
2. รอ 1–2 นาที จะได้ลิงก์ `https://atiwits-porsche.github.io/AITRACK/`

### 3. ตั้งค่าลิงก์สำหรับอีเมลยืนยัน
Supabase → **Authentication → URL Configuration**
- **Site URL**: `https://atiwits-porsche.github.io/AITRACK/`
- **Redirect URLs**: เพิ่ม `https://atiwits-porsche.github.io/AITRACK/`

> 💡 ถ้าใช้คนเดียว/ในครอบครัว ไปที่ **Authentication → Sign In / Providers → Email** แล้วปิด *Confirm email* ได้ เพื่อสมัครแล้วใช้ได้ทันที
> (อีเมลในตัวของ Supabase ส่งได้จำกัดไม่กี่ฉบับต่อชั่วโมง)

### 4. ใช้งาน
เปิดลิงก์บนมือถือ/คอม → สมัครสมาชิก → เข้าสู่ระบบด้วยอีเมลเดียวกันบนทุกเครื่อง
บนมือถือกด "แชร์ → เพิ่มลงในหน้าจอหลัก" เพื่อใช้เหมือนแอป

**ไม่อยากใช้ Supabase?** ปล่อย `js/config.js` ว่างไว้ แอปจะทำงานแบบเก็บข้อมูลในเครื่องเดียว (ส่งออก/สำรองเป็นไฟล์ได้)
หรือกด "ใช้งานโดยไม่ล็อกอิน" ในหน้าเข้าสู่ระบบ

## รันบนเครื่องตัวเอง

```bash
npm start
```

แล้วเปิด http://localhost:8080

## โครงสร้างโค้ด

```
index.html            โครงหน้า + ฟอร์มบันทึก
css/style.css         ธีมสว่าง/มืด, layout responsive, สไตล์สำหรับพิมพ์
js/utils.js           ฟังก์ชันคำนวณ/จัดรูปแบบ (ไม่แตะ DOM, ทดสอบได้)
js/config.js          ค่าเชื่อมต่อ Supabase (URL + anon key)
js/store.js           ข้อมูลในหน่วยความจำ + แคชใน localStorage, หมวดหมู่เริ่มต้น, นำเข้า/ส่งออก
js/cloud.js           Supabase: ล็อกอิน, คิวส่งข้อมูลแบบทนออฟไลน์, ดึงข้อมูล, realtime
js/charts.js          กราฟ SVG (วงกลม, แท่ง) ไม่ใช้ไลบรารีภายนอก
js/app.js             หน้าต่าง ๆ, routing, ฟอร์ม, tooltip, toast
sw.js, manifest.webmanifest   รองรับออฟไลน์และติดตั้งเป็นแอป
supabase/schema.sql   ตาราง + Row Level Security + Realtime
tests/                unit tests (node:test) + e2e ซิงก์ 2 อุปกรณ์ (Playwright + Supabase จำลอง)
```

## ทดสอบ

```bash
npm test          # unit tests
npm run test:e2e  # ทดสอบซิงก์ข้ามอุปกรณ์ (ต้องมี Playwright)
```
